GEMEINSAME VERTRÄGE (von rfx-p0 in src/core angelegt, alle nutzen sie):
- Slot-Tabelle `packages/render-fx/src/core/slots.ts` (verbindlich): render belegt UBO-Slots 0 Frame, 1 Palette, 2 Pass (jeder Pass nutzt SLOT_PASS=2 für seinen eigenen Block), 3 TerrainHeight und Textur-Units 0–7; 4–5 bzw. 8–9 bleiben frei für render/MS3. FX: `SLOT_FX_VIEW = 6`, `SLOT_FX_SHADOW = 7`, `SLOT_FX_SCORCH = 8`; `UNIT_FX_SHADOW_STATIC = 10`, `UNIT_FX_SHADOW_DYNAMIC = 11`, `UNIT_FX_CURVE_LUT = 12`, `UNIT_FX_SCORCH_DATA = 13`, `UNIT_FX_SCORCH_CELLS = 14`; `FX_TIME_WRAP_S = 4096` (FX-Zeit im Shader = Sekunden mod 4096, Alter = mod(now − t0 + 4096, 4096), Lebensdauern ≤ 60 s). Post-Passes sind eigenständige Fullscreen-Passes mit eigenen Units 0/1.
- Frame-Uniforms: alle 3D-FX-Passes binden render's `FRAME_BLOCK_GLSL`/`FRAME_LAYOUT` an SLOT_FRAME (in der späteren Integration liefert der render-Renderer diesen Puffer) und den FX-View-Block an SLOT_FX_VIEW:
  `layout(std140) uniform FxView { vec4 u_fxRight; vec4 u_fxUp; vec4 u_fxFwd; vec4 u_fxTime; };` (xyz = Kamera-Rechts/Hoch/Blickrichtung in Weltachsen; u_fxTime.x = FX-Zeit s mod 4096, .y = dt, .z = Pixel pro WU in Distanz 1 (0,5·viewportH/tan(fovY/2)), .w = Kameradistanz WU). Jeder FX-Pass bekommt im Konstruktor `bindings: FxBindings = { frame: BufH; fxView: BufH }` und baut damit seine Bind-Groups.
- Pass-Konvention: `encode(enc: PassEncoder): number` (gibt Draws zurück), `destroy(): void`, `readonly stats`. Transparente FX-Passes: depthTest an, depthWrite aus, blend 'premultiplied' (additiv = Alpha 0), Reihenfolge PLAN §3.7: … Units → Shields → Particles → Beams/Trails → Post.
- Smoke-Harness (rfx-p0): `pnpm --filter @faf/render-fx run smoke -- --cases=<a,b> --browsers=chromium[,firefox,webkit]` baut packages/render-fx/smoke per Vite, lädt jeden Fall aus `packages/render-fx/smoke/cases/<name>.ts` (Export `smokeCase: SmokeCase`, Interface in `smoke/case.ts`) in Headless-Browsern (Launch-Flags wie Root-playwright.config.ts), prüft GL-/Shader-/Page-Fehler, führt `check()` aus, macht Context-Loss → Restore → erneut frame()+check() (falls WEBGL_lose_context vorhanden) und speichert Screenshots nach test-results/render-fx-smoke/<case>-<browser>.png. Screenshots SELBST ANSEHEN (Read-Tool auf die PNG) und visuell beurteilen.
